# CRUD UTILIZANDO VETORES EM PORTUGOL

Este projeto simula, de maneira simples e objetiva, um sistema de cadastro de pessoas utilizando vetores, funções e a linguagem de programação Portugol.

Por meio desse sistema, é possível cadastrar uma pessoa no vetor, consultar pessoas cadastradas, atualizar os dados de uma determinada pessoa, bem como excluir uma pessoa.


# Organização

O projeto divide-se em algumas funções, sendo: menu, cadastrar, consultar, atualizar e excluir.

## Menu de opções

No menu de opções é possível selecionar a operação desejada.

## Função cadastrar()

Na função cadastrar, um nome é solicitado para o armazenamento no vetor.

## Função consultar()

Na função consultar, uma iteração é realizada sobre o vetor, permitindo consultar as pessoas já cadastradas.

## Função atualizar()

Na função atualizar, uma iteração é realizada sobre o vetor, permitindo consultar as pessoas já cadastradas. Em seguida, é possível atualizar com base no índice do valor armazenado.

## Função excluir()

Na função excluir, uma iteração é realizada sobre o vetor, permitindo consultar as pessoas já cadastradas. Em seguida, é possível excluir com base no índice do valor armazenado. Nesse caso, o valor será substituído por um valor em branco.
